⏳ Safe Reset Actions

Defaults to previous commit (HEAD~1).
Soft Reset (keep staged) SAFE

Moves HEAD to the target revision. Keeps all changes in the staging area. Zero work is lost.

Mixed Reset (unstage) SAFE

Moves HEAD to target revision and resets staging area. Preserves all changes in your working directory.

Hard Reset (discard changes) DESTRUCTIVE

Resets index and working tree. Any uncommitted changes since target revision are permanently discarded!
